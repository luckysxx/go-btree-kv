# 叶子分裂：按字节选择合法切点

状态：已有正文 · 代码：[leaf_split.go](../../btree/leaf_split.go) 的 `leafSplitPoint`

## 问题

叶子装不下时，要把有序记录分成两页。分组必须是连续的 key 区间，不能交错；而且每页都有自己的页头和 offset 表。按**记录数量**取中点可能让某一页超出容量，所以要按实际**字节占用**选切点。

本篇只讨论两页切点的选择；结果页如何重建见 [插入与分裂](08-leaf-insert-and-split.md)，两页无解时见 [三页兜底](09-leaf-three-page-fallback.md)。

## 累计占用与切点

`prefix[m]` 是前 m 条记录的占用字节，包含每条 2 字节 offset 表项和 klen/vlen/key/value，不含页头。`prefix[0] = 0`，n 条记录时数组长 n + 1。对已编码的页，m > 0 时 `prefix[m] = 2*m + offset[m-1]`；插入或覆盖后的新序列需要重新累计，不能沿用旧页的值，也不必先编码出一张超容量的页。

```text
切点 m：左组 [0, m)，右组 [m, n)
left  = 12 + prefix[m]
right = 12 + prefix[n] - prefix[m]
```

规则：先保证两边非空且都 ≤ 4096，再在合法切点中最小化 `|left − right|`。目标是接近**累计字节**的一半，而不是记录数的一半。累计占用单调递增，可以二分定位半数附近的候选；这里顺序扫描所有切点，O(n) 时间、O(1) 额外空间（不含构建累计数组），便于检查。

并列时选较小的 m，使结果确定。这是本实现的选择，不是 B+Tree 的普遍要求，也不保证对所有写入模式最优。

## 例子

- 记录占用 `[2500, 1600, 200, 200]`，prefix = `[0, 2500, 4100, 4300, 4500]`。按数量取 m = 2，左页 12 + 4100 = 4112 字节，超页；m = 1 得到 2512 与 2012 字节，两边合法。
- 只有 `[4084, 4084]` 时，两页加各自页头正好各 4096，可以切。若漏算页头，`[4090, 4090]` 会被错误接受。
- `[1000, 4000, 1000]`：每条单独都装得下，总量也小于两页可用容量，但两个切点都会让某一组包含 5000 字节，**两页切法不存在**，函数返回 false。

## 契约

`leafSplitPoint(prefix) (m, ok)` 是只读的选择函数，累计数组由调用者保证合法，不解析不可信的磁盘字节。`(m, true)` 只说明怎样分组；`(0, false)` 表示不足两条或没有合法的两页切法。它保持纯粹的两页语义，多页由调用层处理。
