# 全树不变量与模型测试

状态：部分已整理 · 代码：[check.go](../../btree/check.go) 的 `tree.check`

## 全树检查

`tree.check() (height int, err error)` 遍历整棵树验证结构不变量，做法类似 bbolt 的 `tx.Check`：正常读写路径信任页内容，需要时单独做一次全树检查。

| 不变量 | 违反时的例子 |
| --- | --- |
| 每张页可读、类型已知 | 页类型为 7 |
| 每张页只被引用一次（同时排除环与共享子树） | 两个目录项指向同一张叶子 |
| 所有叶子同深度 | 根的一个孩子是叶子，另一个是内部页 |
| 内部页非空；除根以外的叶子非空 | 删空的叶子没被摘掉 |
| sibling 为 0 | CoW 树不维护叶子链（见 D05） |
| 页内 key 严格递增 | 重复或逆序 |
| 目录 minKey 等于孩子子树实际最小 key | 删掉 dog 后父目录仍是 dog |
| 孩子子树的所有 key 落在 `[本项 minKey, 下一项 minKey)` 内 | 左边叶子里出现了属于右边子树的 key |

最后一条是子树范围检查：递归时把上下界传给孩子，保证兄弟子树之间范围不重叠。出错返回带页号与原因的 `ErrCorruptTree`（缺页为 `ErrPageNotFound`）。

### 引用唯一：全局集合而不是路径

`getFrom` / `insert` 的 `visited` 只记录从根到当前页的一条路径，能发现环，但发现不了"两个兄弟目录项指向同一张页"：两次访问分别在两条路径上。全树检查用一个全局的 `seen` 集合，任何页第二次出现都算错。这样一并排除了环，也排除了共享子树。

### 范围要从祖先继承

只检查"叶子的 key 小于父页右侧的 minKey"不够。内部页**最后一个**孩子在本页里没有右邻目录项，它的真实上界来自更上层：

```
           R [a | m]
          /         \
     I [a | c]      ...
      /    \
   [a b]  [c z]     ← z ≥ m，属于 R 的右子树
```

每层的 minKey 都对得上，页内也有序，但查找 z 会走到 R 的右边，找不到它。做法是：孩子的上界默认继承本页的上界，本页有右邻目录项时再收紧为它的 minKey。这样每一层的范围都是所有祖先约束的交集。内部页自己的目录 key 也要在范围内。

### 信息双向流动

- **上下界从上往下传**：祖先规定孩子子树只能放什么。
- **子树最小 key 从下往上交**：`walk` 返回子树实际最小 key，父页拿它和目录项比较，要求相等。

两者缺一不可。只做范围检查，过时的 minKey 能通过（实际最小 key 大于 minKey，仍在范围内）；只比较 minKey，深处越界的 key 能通过。

### 空叶子与树高

除根以外的叶子不能为空；根叶子可以为空，那就是空树。叶子深度用一个全局值记录：遇到第一张叶子时记下，之后每张叶子都要与它相同。这个值就是树高，`check` 把它返回给测试，用来断言根分裂、根收缩之后的高度。

### 工业对照：bbolt tx.Check

bbolt 同样递归携带 `[minKey, maxKey)` 检查 key 的顺序。它多做的是页空间的账目：页不能被引用两次；不能既可达又在空闲列表中；高水位以内的每张页要么可达、要么空闲，否则就是泄漏。后两项依赖空闲页管理，引入页回收后（E 组）才能检查。

测试中的每步检查都调用它：Put、根分裂、Delete 的随机测试在每一次操作后都做全树检查。

## 参考模型对照

用一个 Go map 作为参考模型，对同一串操作分别施加到树和 map 上，再比较：

- Put：随机插入/覆盖后逐个 key 比较，并检查若干不存在的 key。
- Scan：游标读出的结果与 map 排序后的区间逐条比较。
- Delete：随机插删混合，最后全部删空。
- 快照：中途保存根页号和 map 的副本，之后继续修改，最后检查旧根仍然对应旧 map。

随机操作使用固定种子，失败可以复现。随机测试难以覆盖的前提（例如新根一定装得下一页）另写显式测试。
